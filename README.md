# Recipe Webpage

## About the Project
This project is a simple recipe webpage created to practise structuring information with HTML. It presents a recipe, its ingredients, and its preparation steps in an organized format.

## What I Practised
- Using headings and paragraphs.
- Creating unordered lists for ingredients.
- Creating unordered lists for preparation steps.
- Organizing information using semantic and appropriate HTML elements.

## Technologies Used
- HTML5

## What I Learned
This project helped me understand how the choice of HTML element affects the way information is organized. I learned to use unordered lists when the order of items is not essential.

## How to View the Project
Open recipe.html in a web browser.
